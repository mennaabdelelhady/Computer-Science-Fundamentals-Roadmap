# Computer Science Fundamentals Roadmap 💻

Core CS theory to back up my full-stack/Laravel/.NET work — data structures, systems, and how things actually run under the hood.

> Rule: finish one stage before starting the next. No course-collecting.

---

## Stage 0 — CS Foundations Refresher (optional, skip if confident)

- [ ] Week 0 — Scratch / computational thinking
- [ ] Week 1–2 — C (memory, arrays, pointers)
- [ ] Week 3 — Algorithms (sorting/searching)
- [ ] Week 5 — Data structures
- [ ] Week 7 — SQL
- [ ] Week 8 — HTTP / web basics

## Stage 1 — Data Structures & Algorithms
**Course:** [MIT 6.006 — Introduction to Algorithms (Spring 2020)](https://www.youtube.com/playlist?list=PLUl4u3cNGP63EdVPNLG3ToM6LaEUuStEY) · [course site](https://ocw.mit.edu/6-006S20)

- [ ] Arrays, sorting, hashing
- [ ] Binary trees, heaps
- [ ] BFS / DFS, graph traversal
- [ ] Shortest paths (Dijkstra, Bellman-Ford)
- [ ] Dynamic programming
- [ ] Complexity analysis / proofs
- [ ] Practice: solve 15–20 problems per topic on your own (e.g. LeetCode) alongside lectures

## Stage 4 — Computer Networks
**Course:** [Stanford CS144 — Introduction to Computer Networking](https://www.youtube.com/playlist?list=PLvFG2xYBrYAQCyz4Wx3NPoYJOFjvU7g2Z) · [course site](https://cs144.github.io/)

## Stage 5 — Database Systems (internals, not just SQL)
**Course:** [CMU 15-445/645 — Intro to Database Systems (Andy Pavlo)](https://www.youtube.com/playlist?list=PLSE8ODhjZXjYDBpQnSymaectKjxCy6BYq) · [course site](https://15445.courses.cs.cmu.edu/)

- [ ] Relational model & advanced SQL
- [ ] Storage & buffer pools
- [ ] Indexes (B+ trees, hash indexes)
- [ ] Query execution & optimization
- [ ] Concurrency control
- [ ] Crash recovery
- [ ] Optional project: BusTub (CMU's teaching DBMS, on GitHub)

---

## Stage 6 — Capstone Project 🎯

- [ ] Pick a systems-flavored feature to build (e.g. a mini key-value store, a caching layer, or a custom indexing scheme inside **3ilajak**)
- [ ] Design it using what you learned (data structures, concurrency, storage)
- [ ] Implement MVP
- [ ] Load test / benchmark it
- [ ] Write up what broke and what you learned
